# 红笔 1.0.0 · 版本更新说明

- 发布日期：2026-11-20
- 应用版本：`1.0.0+1`（Windows 文件版本 `1.0.0.0`）
- 代码仓库：<https://github.com/SubmergeDQ/Red-Pen>
- 适用平台：Windows 10 1809 及以上（x64）、Android 8.0（API 26）及以上（arm64-v8a / armeabi-v7a / x86_64）

这是红笔首个正式发行版。判定引擎、规则库与既有界面保持不变，本次新增「启动自动更新检查」与双端「关于」页面，并把版本号正式定为 1.0.0。

---

## 一、新增功能

### 1. 启动自动检查更新

- 每次启动后，应用向 GitHub Releases 接口读取公开版本列表，与本地版本比对；发现更高版本时弹出更新提示。
- 桌面端为居中的更新对话框，Android 为底部弹出的更新卡片；两者都包含：
  - 当前版本 → 最新版本；
  - 最新版本的更新说明（纯文本展示，自动去掉 Markdown 标记）；
  - 「下载更新」：Windows 优先选择 `.exe` 安装程序，其次 `.zip` 便携包；Android 按 CPU 架构选择对应 APK；
  - 「稍后再说」与「跳过此版本」。
- 提示频率控制：
  - 同一次运行最多提示一次；
  - 选择「跳过此版本」后，该版本不再提示；只有出现更高版本时才重新提示；
  - 草稿发行版不参与比对，预发布版本（beta / rc）不会被推荐为正式更新。

### 2. 双端「关于」页面

桌面端从左侧栏「应用 → 关于红笔」打开弹窗；移动端从顶栏信息图标进入独立页面。两端内容一致：

| 模块 | 内容 |
|---|---|
| 版本 | `v1.0.0 (1)` 版本徽标 |
| 更新 | 当前状态、检查时间、「检查更新」按钮、发现新版本时的下载与跳过操作、最新更新说明 |
| 历史版本 | 最近 8 个发行版，可展开查看完整更新日志；标记「当前版本」与「预览版」 |
| 运行环境 | 应用版本、运行平台、处理器架构、屏幕逻辑尺寸、像素密度、界面语言、识别引擎、规则库规模 |
| 代码仓库 | 官方 GitHub 地址，支持复制与打开 |
| 隐私 | 合同正文只在本机解析与核对；更新检查只读取公开版本信息 |

「运行环境」为实时读取，不写死：平台版本来自操作系统，架构来自 `dart:ffi`，屏幕与语言来自当前会话，识别引擎来自当前 OCR 实现。

### 3. 版本比较

- 按语义化版本逐段做数值比较，`1.10.0` 正确高于 `1.9.9`；
- 兼容 `v1.0.0`、`release-1.2.3` 等常见 tag 写法，忽略 `+build` 元数据；
- 正式版高于同号预发布版（`1.0.0` > `1.0.0-beta.2`）。

## 三、验证记录

- `flutter analyze`：0 error / 0 warning。
- `flutter test`：89 项全部通过（引擎黄金用例、29 条规则用例、PDF/OCR 流水线，以及本轮新增的版本比较、发行版解析、更新状态机用例）。
- Windows 实机：
  - 启动后自动读取发行版；临时发布 `v1.0.1` 时正确弹出更新提示；
  - 点击「跳过此版本」后写入本地状态，重新启动不再提示；
  - 删除测试发行版后不再误报；
  - 关于页桌面弹窗与窄窗（移动布局）页面均渲染正常，环境参数读取正确；
  - 更新检查遇到 GitHub 限流时显示可读提示，不崩溃、不误报有新版本。
- Android：
  - 三个分架构 APK 均构建通过并验签；
  - 合并后的清单包含 `INTERNET` 权限，以及 Android 11+ 打开浏览器的 `https` 可见性声明；
  - 每个 APK 只包含本架构 `lib/`，中文 OCR 模型与 PDF 字体齐全。
- 未覆盖：本机没有 Android 真机 / 模拟器，安卓端更新提示与关于页仅完成构建与静态验证；macOS 未在本次构建范围内。

## 四、隐私与网络说明

- 合同正文仍然只在本机解析、核对，不上传、不落盘。
- 本版起，应用会在启动时访问 `api.github.com` 读取公开的发行版信息；这是唯一的网络请求，不携带任何合同内容、设备标识或使用数据。
- 安装包下载通过系统浏览器打开 GitHub 页面，由用户自行确认安装。
- 如果网络不可用或 GitHub 限流，更新检查会安静失败并在关于页给出提示，不影响合同核对功能。

## 五、已知限制

- 更新为「提示 + 跳转下载」，不做静默下载与自动安装；Windows 安装包与 APK 均需用户手动确认。
- GitHub 未认证接口对同一出口 IP 限制 60 次/小时；共享网络下可能短暂提示「请求频率受限」，稍后重试即可。
- macOS 版本未包含在本次发行中；仓库内的 `installer/package_macos.sh` 仅作为打包脚本参考，未经验证。
