# 红笔 1.1.0 · 版本更新说明

- 发布日期：2026-11-20
- 应用版本：`1.1.0+4`
- 代码仓库：<https://github.com/SubmergeDQ/Red-Pen>
- 适用平台：Windows 10 1809 及以上（x64）、Android 8.0（API 26）及以上

1.1.0 是一次完整的界面重构：1.0 的纸面／衬线／侧栏方案全部退役，新的「墨线」设计系统覆盖桌面与移动端；同时替换了全平台应用图标，并把主题、响应式与命令扩展接口沉淀为可复用的架构。

---

## 一、这次改了什么

### 1. 全新 UI，不是换色

- 冷白画布 + 纯白卡片 + 墨蓝结构色 + 一道朱红强调色；四色判定重新调校，保持语义不变。
- 单一无衬线字族，八级字体角色；间距、圆角、阴影、动效全部收敛到设计令牌。
- 桌面端改为顶部导航 + 固定底部操作栏；移动端为紧凑顶栏 + 分段切换 + 底部操作栏。
- 交稿台、核对中、核对报告、关于页、核对依据、更新提示、确认弹窗全部重写。
- 旧的 `theme.dart`、`ui/common.dart`、`ui/desktop_shell.dart` 已删除，不再保留双套实现。

### 2. 报告与关于页

- 报告页：一句结论、四级统计（可点筛选）、报告/原文双栏；卡片展开后依次展示原文、法律依据、问法、改法与定位。
- 移动报告：摘要与统计条进入滚动内容，底部固定「导出 PDF / 复制报告」。
- 关于页：品牌标识、版本徽标、更新管理、历史版本、运行环境、代码仓库、隐私说明统一为新组件。

### 3. 全平台新图标

- 源文件来自新的应用图标包：纸面 + 朱红圈注。
- Android：legacy、round、adaptive foreground/background、monochrome 全量替换，启动画面改为品牌底色 + 图标。
- Windows：多尺寸 `.ico`；Web：favicon、192/512 常规与可遮罩图标、manifest 名称与主题色。
- 应用内品牌标识改为同一图标，不再使用手绘印章。

### 4. 架构扩展位

- `design/`：设计令牌、主题、图标表、原子组件分层。
- `AppThemeConfig` / `AppThemeTokens`：全局主题配置与运行时扩展位。
- `AppCommand` + `AppShell.extraCommands`：新功能可以插进桌面顶栏或移动更多菜单，不改外壳。
- `AppLayout` / `AppBreakpoints`：compact / medium / expanded 三档，为平板、折叠屏、超宽屏预留。

### 4.1 规则引擎与双端一致性

- 运行时规则库扩展至 **R1–R30**，覆盖劳动合同、试用期、实习协议、三方协议、培训贷与劳务/兼职场景；Web（`engine.js`）与客户端（`engine.dart`）使用同一套判定逻辑。
- 新增 R21–R30：必备条款缺失、经济补偿与违法解除、无固定期限、特殊工时审批、女职工三期、工伤申报、个人信息与背景调查、非全日制/派遣外包、电子签署、争议管辖与送达。
- `engine_parity_test.dart` 继续以黄金文件逐字段比对两端输出，包含判定、金额、条款定位、问法与改法，避免 Android / Windows 与 Web 出现结论差异。
- 本轮补强句子级排除、劳动者/用人单位主语识别、金额与百分比解析、多规则包调度；R4 服务期豁免、R12 甲方通知期、R15 个人社保代扣等历史误报均有回归用例。
- 《规则优化规范 v2》：`docs/rules-v2.json`，包含 R1–R30 的红/橙/绿判据、同义/口语表述、正反例与替换条款，已与运行时实现同步。

### 5. 更新与隐私

- 启动更新检查、跳过版本、历史版本与更新说明保持不变，全部迁入新设计。
- 合同正文仍只在本机解析与核对；网络请求仅用于读取 GitHub 公开发行版信息。

### 6. 1.1.0 修订（+3）

- Windows 窗口位置记忆：关闭时记录坐标、尺寸与最大化状态，下次启动原样恢复；首次启动居中并夹到工作区，默认窗口完整展示交稿台全部内容。
- Windows 图标链路补齐：exe、安装程序、桌面/开始菜单快捷方式统一使用新图标。
- Android 启动图标主体缩小、四周增加背景留白，legacy / 圆形 / adaptive 三套资源同步。
- 窄屏编辑器头部改为两行：标题与清空一行，合同类型与字数一行，解决「合同正文」折行、类型与字数拥挤的问题。
- 「签约前 5 分钟」改为横向双段徽标：「签约前」在左、「5 分钟」以强调色紧随其右，双端共用同一组件，不换行。

### 7. 1.1.0 修订（+4）

- **Android OCR 修复**：release 包的 R8 裁剪会破坏 ML Kit 通过反射建立的识别器注册表，`TextRecognition.getClient` 因而抛出空指针。现已整体保留 `com.google.mlkit.**` 与 `com.google.android.gms.internal.mlkit_**`，独立图片与扫描版 PDF（内嵌图片）两条识别链路在真机 release 包上均通过。
- **首页排版**：「签约前 5 分钟」移到标题行右侧，省出一行垂直空间；桌面右栏按可用高度自动收紧行距并收起「覆盖范围」说明，卡片内容不再被底边裁切。
- **Windows 图标**：窗口显式设置大小图标（`WM_SETICON`），进程与快捷方式统一 `RedPen.Desktop.1`，任务栏不再回落到默认图标；桌面与开始菜单快捷方式继续引用 exe 内的新图标。
- **Windows 首页不滚动**：桌面交稿台改为固定高度两栏布局，页面本身不再上下滚动，长文本由编辑器内部滚动；最小窗口 1080×700（随 DPI 换算），默认窗口 1320×900，首次启动即完整展示。

## 五、已知限制

- 更新仍是「提示 + 跳转下载」，不静默安装。
- GitHub 未认证接口对同一出口 IP 限制 60 次/小时，共享网络下可能短暂提示限流。
- 运行时深色/换色接口已预留，但自定义组件尚未全部迁移。
- macOS 未包含在本次发行中。
